# Interface review, 2 November 2026

Why the interface feels cluttered and unintuitive, from going through every screen on a scratch
library. Input for the redesign (T34, widened from read and study modes to the whole interface).

## What works

- **Print or save** is the model to follow:
  - one main button ("Print"), then "or save as" PDF, Word, Web page or Markdown;
  - a real preview;
  - More options folded away.
- **Reports** read cleanly: one sentence of explanation, one input, sections that can be collapsed, and
  every reference a link.
- **Get Bibles**, **Add books** and the **change** links for licences and types are simple.

## Problems

1. **Too many top-level sections (eleven).** Reader, Bibles, Library, Notes, Lists, Plans, Sermons,
   Reports, Search, Settings, Commands. Each task added its own section. Notes, Lists, Plans, Reports
   and Sermons are all study tools, and Commands is a developer console.
2. **The Reader puts everything before the text.**
   - **Toolbar:** eight controls in two rows (passage box, Read, Passage report, the Bible chips, Notes
     beside the text, Print or save, Open a book, Previous chapter, Next chapter).
   - **Reading plan:** the catch-up box takes the top third of the screen.
   - **The Bible text** starts halfway down.
3. **One side column holds everything.** Commentary, cross-references, the word panel and notes stack in
   a single column. The note form ends up under long commentary, and its Save button can fall off
   screen.
4. **Every view shows all its controls at once.** Notes has four filter menus; Sermons has a search, two
   menus and a New button before any content; the Reader shows chapter navigation as large buttons.
5. **Inconsistent patterns.**
   - Some views start with an explanation sentence, others don't.
   - "New" sits in different places.
   - Some lists have Recently deleted as a button, others as a link.
6. **No home.** The app opens on the last Reader state, with no calm starting point ("continue reading",
   today's reading, recent books).

## Proposed direction (to confirm with a mock-up before building)

- **Four places in the sidebar: Read, Library, Study, Settings.**
  - **Read:** the shared document renderer (T34) for Bibles and books, opening where you left off.
  - **Library:** books and Bibles together, including Get Bibles and Add books.
  - **Study:** notes, lists, plans, reports and sermons as tabs inside one place.
  - **Commands:** moves under Settings → Advanced.
- **The reading screen:**
  - text first;
  - a slim top bar with the passage box and the Bible picker;
  - chapter arrows at the edges;
  - everything else in a right-click menu or one side panel with tabs (Notes, Commentary, Word,
    Cross-references), closed by default in read mode.
- **Today's reading** is a one-line strip ("Day 7 · Genesis 21–23 · 3 behind"), expanded only on click.
- **One pattern for every list:**
  - search box;
  - a New button at the top right;
  - filters under More filters;
  - Recently deleted at the bottom.
- A short home or start strip: continue reading, today's reading, recent items.
