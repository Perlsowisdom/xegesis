# 0007: Clean-room design from public sources

## Decision

Xegesis's features come from the Phase 1 functional survey, open-source projects and published
specifications. No commercial Bible software is studied, run, decompiled or copied during design or
development. Rules are in `AGENTS.md`.

## Provenance

Each pull request that adds a feature names its source: a Phase 1 survey row, a specification, or an
open project. The Phase 1 survey lists features documented publicly before 6 April 2026, excluding AI
features.
